# 简历专家

✏️ 帮应届生把简历改得更清楚、更具体。

这是一个装在你自己电脑上的小工具。把岗位要求和现在的简历贴进去，它会帮你看差距、改写法，并准备可能被问到的问题。分析用的是你自己的大模型，费用记在你自己的账号上。

## 🧰 你需要准备

- 一台电脑。下面的双击启动只适用于 Windows。Mac 没有这个小窗口，请用后面的提示词交给 AI
- Node.js。第一次用的话，按你的系统复制对应提示词，交给 AI 助手帮你装
- 一个大模型的 API Key。建议先用 DeepSeek，申请比较直接

## 🚀 第一次打开

先在本仓库页面点击绿色的 **Code**，选择 **Download ZIP**，下载后解压。

### Windows

1. 把下面这段话复制给你的 AI 助手（Cursor、豆包或其他都可以），让它在解压出来的文件夹里把环境装好。

```text
请帮我在这台 Windows 电脑上安装 Node.js，使用当前的 LTS 版本。装好后，进入我解压出来的「简历专家」项目文件夹，运行 npm install。不要修改代码，也不要把任何 API Key 写进文件。
```

2. 双击文件夹里的 **启动简历专家.bat**。
3. 在弹出的小窗口里点 **开始**。浏览器会打开这个工具。
4. 用完点 **关闭**。直接关掉小窗口也可以，工具会一起停下来。

如果小窗口写着还没有 Node.js，或还没有安装依赖，把上面那段话再交给助手做一次，然后重新点 **开始**。

### Mac

Mac 上没有「开始 / 关闭」那个小窗口。程序本身可以在 Mac 上跑，安装和启动交给 AI 做就行。

下面这段提示词会让 AI 帮你装好 Node.js、装上依赖，并打开网页。它不会改项目代码，也不会把 API Key 写进文件。Key 仍然由你自己在网页里填写。

用法：

1. 复制下面整段提示词。
2. 在 Mac 上打开 Cursor 或其他 AI 助手，把提示词粘贴进去。
3. 告诉它解压后的「简历专家」文件夹在哪里，或直接在那个文件夹里打开助手。
4. 等它说网页已经打开后，用浏览器访问它给你的地址，再按下一节配置 API。
5. 用完后，回到 AI 打开的那个终端窗口，按 `Control + C`，程序会停下来。

```text
我在 Mac 上使用「简历专家」这个本地简历工具。请帮我完成这些事：
1. 如果还没有 Node.js，请安装当前的 LTS 版本。
2. 进入我解压出来的项目文件夹，运行 npm install。
3. 运行 npm run dev:all，等它启动后，在浏览器打开 http://127.0.0.1:5173/ 。
4. 用白话告诉我网页是否已经打开，以及用完后怎么按 Control + C 停掉。

不要修改项目代码，也不要把任何 API Key 写进文件。
```

## 🔑 配置 API

网页打开后，点右上角 **设置 API**。

建议先填 DeepSeek：

| 填写项 | 内容 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com` |
| 模型名称 | `deepseek-v4-pro` |
| API Key | 打开 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 申请，再粘贴到这里 |

地址填到域名为止。后面不要加 `/chat/completions`。

先点 **检测连接**。看到连接成功后，再点 **保存**。

密钥只留在这台电脑上。保存之后，页面不会再显示完整密钥。

还没决定用哪一家时，可以把下面这段话交给助手，让它用白话帮你选。Key 由你自己申请，自己粘贴进网页。

```text
我想用一个叫「简历专家」的本地简历工具。请用白话比较 DeepSeek、智谱、豆包，告诉我哪一个更适合新手，并给出三样东西：接口地址、模型名称、申请 API Key 的网页。不要替我申请，也不要把 Key 写进任何文件。
```

也可以换成这两家，只要填它们自己的地址和模型名称：

- 智谱：接口地址 `https://open.bigmodel.cn/api/anthropic`，模型名称 `glm-5.2`
- 豆包（火山方舟）：接口地址 `https://ark.cn-beijing.volces.com/api/v3`，模型名称用你账号里已经开通的那个

## 📄 先把简历变成 Markdown

这个工具读得懂的是 Markdown。它是一种纯文字格式，用 `#` 当标题，用 `-` 当列表。Word、PDF 和聊天里的普通排版，贴进来会认不准。

你不用自己学这个格式。把现有简历发给任何一个 AI，让它按原文转成 Markdown，再把结果贴进本工具。

下面这段提示词是为了让 AI **只换格式、不改内容**。如果只说「帮我转成 Markdown」，它常常会顺手润色、删句子，后面的修改就不是基于你的原文了。

用法：

1. 复制下面整段提示词。
2. 打开豆包、ChatGPT 或其他任何一个 AI，先粘贴提示词。
3. 在提示词最后面贴上你的简历。Word 里直接复制文字，PDF 可以上传文件。
4. 等它回复后，把整段 Markdown 复制下来。
5. 贴进本工具的 **原始简历**。岗位要求如果也是文档，用同样的方法转一次，贴进 **目标校招岗位 JD**。

```text
请把我下面贴出的简历原样转换成 Markdown。
要求：
- 只做格式转换，不要改写、不要润色、不要删减
- 保留原来的公司、岗位、时间、项目和数字
- 用标题和列表排好，方便我复制
- 只输出 Markdown 正文，不要解释

简历正文从这里开始：
```

## ✍️ 开始改简历

1. 选好目标岗位、行业和投递场景。
2. 把岗位要求贴进 **目标校招岗位 JD**。
3. 把转好的简历贴进 **原始简历**。经历材料能填就填，修改会更准。
4. 点 **开始分析**，等结果出现。
5. 按页面上的步骤往下看。需要补充经历时，按提示回答，再继续改。
6. 走到后面可以点 **导出 Markdown**，把这次改好的报告存成文件。

## 🌱 这一版还比较粗糙

界面和操作都做得比较简单，能完成改简历，但还不好看，也不够顺手。

为了少花模型费用，输入和导出都只用 Markdown，没有做成精致的 Word 或 PDF。

欢迎二创 ✨。改界面、加导出格式、调整修改流程，都可以。如果你做出了更好的版本，欢迎分享出来。

## 💡 使用时注意

- 密钥留在自己电脑上，不要发到网上，也不要提交到 GitHub。
- 每次修改都会消耗你账号里的额度，简历越长，花费越多。
- 小窗口如果提示端口被占用，先点 **关闭**，再点 **开始**。
